# Phantom Company Frontend

Browser prototype for the Phantom Company guild-management RPG.

## Requirements

- Node.js 24 LTS
- npm 11 or newer

## Commands

```powershell
npm install
npm run dev
npm run build
npm run lint
```

The first playable slice lets a player choose Training, Raiding, or Rehab, sign the founding charter, and inspect the resulting guild state and Phantom Squire.
